Geschafft! Sie haben alle Puzzleteile platziert.

Spielanleitung

  • Wählen Sie eine Schwierigkeitsstufe aus, um das Spiel zu starten.
  • Desktop: Ziehen Sie die Puzzleteile in das Sudoku-Gitter.
  • Mobile: Tippen Sie ein Puzzleteil und dann eine Zelle an, dann "Platzieren".
  • Doppelklicken/Doppeltippen Sie auf eine leere Zelle, um eine Zahl einzugeben.
  • Klicken/Tippen Sie auf ein platziertes Puzzleteil, um es zu entfernen.
  • Füllen Sie das gesamte Gitter aus, um das Spiel zu gewinnen.
  • Bei mittlerem und schwerem Schwierigkeitsgrad können Sie die Puzzleteile drehen.
  • Bei schwerem Schwierigkeitsgrad wird eine Zahl pro Puzzleteil versteckt.

Seed-System

  • Seed eingeben: Geben Sie eine Zahl oder Text ein für reproduzierbare Puzzles.
  • Heutiger Seed: Verwenden Sie den täglichen Seed - alle spielen das gleiche Puzzle!
  • Zufälliger Seed: Generiert einen neuen zufälligen Seed.
  • Seed teilen: Kopieren Sie den Seed und teilen Sie ihn mit Freunden.
  • Leer lassen = komplett zufälliges Spiel
